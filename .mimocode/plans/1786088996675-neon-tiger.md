# Plan: Modals, Popups & Interactive Overlays

## Problem

27 placeholder/broken actions across 12 admin files. Buttons with `href="#"`, `console.log`, or no `onClick` handler. The app needs a reusable modal system and wire up all the missing interactions.

## Approach

1. Create a reusable `Modal` component
2. Create a reusable `DropdownMenu` component
3. Implement modals by priority tier

---

## Step 1: Create Reusable Modal Component

**New file:** `components/ui/Modal.tsx`

A flexible modal with:
- Overlay backdrop (click to close)
- Close button (X)
- Title, description, content, footer (cancel/confirm buttons)
- Sizes: `sm` (confirmations), `md` (forms), `lg` (multi-step)
- `open` / `onClose` props
- Keyboard escape to close
- Focus trap

```tsx
<Modal open={isOpen} onClose={() => setIsOpen(false)} title="Reset Password">
  <p>Are you sure you want to reset the password for {user.name}?</p>
  <Modal.Footer>
    <Button variant="secondary" onClick={() => setIsOpen(false)}>Cancel</Button>
    <Button variant="primary" onClick={handleReset}>Send Reset Email</Button>
  </Modal.Footer>
</Modal>
```

## Step 2: Create Reusable DropdownMenu Component

**New file:** `components/ui/DropdownMenu.tsx`

A dropdown menu triggered by a button (usually three-dot icon):
- Trigger button
- Floating menu positioned below trigger
- Click outside to close
- Keyboard navigation

```tsx
<DropdownMenu
  trigger={<button><MoreVertical /></button>}
  items={[
    { label: "Edit", icon: Edit, onClick: () => openEditModal(item) },
    { label: "Delete", icon: Trash, danger: true, onClick: () => openDeleteModal(item) },
  ]}
/>
```

## Step 3: Create FileUpload Modal

**New file:** `components/ui/FileUploadModal.tsx`

A modal for CSV/Excel import:
- Drag & drop zone + file picker
- Template download link
- Column mapping preview (first 5 rows)
- Import button with progress
- Success/error feedback
